## 18. الفصول القادمة والتوسع

أضيف قسم «فصول قادمة» بعد المحاور الثمانية، ويضم تسعة فصول ثابتة في الكود: قانون الالتزامات والعقود، القانون الدستوري، التنظيم الإداري، القانون الجنائي العام، المدخل إلى العلوم السياسية، المدخل إلى علم الاقتصاد، القانون المدني، القانون التجاري، وقانون الشغل.

هذه الكروت تحمل شارة «قريباً»، ولا تحتوي على روابط أو أزرار أو معاينات أو أسئلة. كما أضيف تأثير Hover خفيف لجذب الانتباه، مع بقاء الكروت غير قابلة للنقر. عند إصدار هذه الفصول، يحصل المشتركون الحاليون عليها مجاناً وفق مبدأ التحديثات مدى الحياة.

## 19. ما تم تأجيله بوعي

بعض العناصر ليست أعطالاً أو نواقص في النسخة الحالية، بل قرارات مؤجلة إلى مرحلة لاحقة. وتشمل تكامل الدفع الإلكتروني Simple/CMI، تفعيل Watermarking للملفات، التسجيل القانوني أو إنشاء كيان تجاري، صلاحيات الموظفين المتعددين، تحويل الفصول القادمة إلى محتوى ديناميكي كامل، وربط Google Sheets فعلياً بعد نشر Web App والتفويض.

| العنصر | الوضع الحالي |
|---|---|
| الدفع الإلكتروني | مؤجل إلى حين وثائق API وWebhook والاعتمادات |
| Watermarking | مؤجل بوعي |
| الموظفون وصلاحيات متعددة | غير مفعّل حالياً |
| Google Sheets | تصميم المزامنة اليدوية محدد؛ التفعيل الإنتاجي يتطلب نشر السكربت واختباره |
| الفصول القادمة | واجهة ثابتة غير تفاعلية إلى حين تجهيز المحتوى |
| 2FA مستقل داخل التطبيق | الاعتماد الحالي على مزود OAuth؛ التفعيل الفعلي يحتاج إعداد الحساب |

## 20. الحالة النهائية

المنصة في وضع تشغيل منشور، والنسخة الأخيرة متاحة على نطاق Manus. الصفحة العامة تعمل مع المحتوى التسويقي والتعليمي، ومسار الشراء اليدوي موجود، والتسعير المرحلي نشط، والإدارة محمية، والاختبارات والبناء ناجحان. تم حل آخر مشكلة تشغيلية ظهرت للمستخدم، وهي رسالة رفض الوصول بعد اكتمال تسجيل الدخول؛ وقد تبين أن فتح `/admin` قبل تثبيت session cookie يؤدي إلى بوابة الدخول، بينما يؤدي إكمال OAuth ثم العودة إلى ظهور لوحة الإدارة بشكل صحيح.

> **الخلاصة التنفيذية:** MIDAD ليست مجرد صفحة بيع PDF؛ بل نواة منصة تعليمية رقمية عربية قابلة للتوسع، تحتوي على تجربة تسويق، محتوى تعليمي، اختبارات، إدارة طلبات، تسليم آمن، تحليلات، وإدارة محتوى، مع أساس تقني مناسب لإضافة منتجات وفصول ودفع إلكتروني مستقبلاً.
