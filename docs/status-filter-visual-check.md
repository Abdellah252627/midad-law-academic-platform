# فحص مرشح حالات طلبات الشراء

تم التحقق بصرياً من المسار `/admin/purchases` على سطح المكتب 1280×720 والهاتف 375×812. يظهر حقل البحث العربي ومرشح الحالات (كل الحالات، قيد المراجعة، مقبول، مرفوض) مع زر البحث والمسح. الترتيب متجاوب، وتتحول عناصر المرشح إلى تخطيط عمودي مناسب للهاتف، مع بقاء عدادات الطلبات وجدول الإدارة قابلين للاستخدام.

ظهرت في سجل المتصفح رسالة `Missing session cookie` أثناء لقطة الاختبار غير المصادق عليها، وهي متوقعة لأن المسار إداري محمي، ولا تمثل خطأ في مرشح الحالة.

التحقق البرمجي: 23 مجموعة و78 اختباراً ناجحاً، TypeScript ناجح، وبناء الإنتاج ناجح.
