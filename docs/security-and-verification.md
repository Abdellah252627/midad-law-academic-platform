# توثيق الأمان والتحقق الخارجي في MIDAD

## حماية الإدارة

تستخدم لوحة التحكم دور `admin` على مستوى إجراءات الخادم، مع تطبيق rate limiting على طلبات الإدارة. لا يعتمد المشروع على إخفاء المسار؛ فالتحقق الحقيقي يتم في الخادم قبل تنفيذ إجراءات القراءة أو التعديل أو الموافقة أو التصدير.

## المصادقة متعددة العوامل

لا يفرض المشروع طبقة 2FA محلية موازية لمزود Manus OAuth، لأن تسجيل الدخول وإدارة جلسة OAuth تتم خارج التطبيق. الإجراء التشغيلي المعتمد هو تفعيل 2FA من حساب مزود OAuth إذا كان متاحاً في الحساب، ثم اختبار تسجيل الدخول بحساب إداري فعلي. لا يجوز اعتبار وجود زر تسجيل الدخول أو نجاح البناء دليلاً على إتمام 2FA.

تم تنفيذ اختبار OAuth end-to-end بنجاح عبر متصفح بشري صالح من طرف صاحب الحساب، مع اجتياز تحقق Google/Cloudflare. لا يتم تجاوز CAPTCHA أو تعطيلها برمجياً.

## قائمة تحقق ما قبل الإنتاج

| البند | الحالة |
|---|---|
| جدول users موجود ومتوافق مع OAuth | منفذ ومطبق عبر migration |
| حماية إجراءات الإدارة بدور admin | منفذة ومغطاة بالاختبارات |
| Rate limiting لمسارات الإدارة | منفذ ومغطى باختبار Vitest |
| تفعيل 2FA لدى مزود OAuth | مكتمل؛ أكد صاحب الحساب ظهور Authenticator ووسائل الاسترداد مفعلة |
| اختبار OAuth end-to-end | مكتمل عبر متصفح بشري صالح بعد اجتياز Google/Cloudflare |
| التحقق من الوصول الإداري بحساب فعلي | مكتمل؛ تم تأكيد دخول admin وحجب الزائر غير المصادق |

يجب تسجيل نتيجة الاختبار البشري في سجل التشغيل بعد نجاحه، مع عدم حفظ كلمات المرور أو رموز OAuth أو أي أسرار داخل المستودع.

## فحص OAuth وTurnstile ومسار الدعم

أظهر فحص سجلات الخادم تهيئة OAuth بصورة سليمة، بينما لا توجد في السجلات المحلية نتيجة تحقق Turnstile قابلة للإصلاح داخل التطبيق؛ حالات التوقف تقع عند مزود Google/Cloudflare أو تحتاج جلسة متصفح بشرية. لذلك لا يتضمن المشروع أي تعطيل لـ CAPTCHA أو تجاوز لها.

عند فشل التحقق، تكون الرسالة التشغيلية الآمنة هي إعادة المحاولة من متصفح محدث أو جلسة Google صالحة، ثم التواصل مع مسؤول النظام أو مزود OAuth إذا استمر الفشل. لا ينبغي عرض الأسرار أو تفاصيل callback، ولا يجوز توفير مسار تنزيل إداري بديل.

هذا التوثيق يسجل نجاح الاختبار البشري النهائي، مع التأكيد أن أي فشل لاحق في CAPTCHA أو OAuth يجب معالجته عبر متصفح محدث أو مزود OAuth، دون تخفيف حماية المصادقة أو توفير مسار بديل.

## حماية ملفات PDF ومخاطر المشاركة

حد رفع ملف المنتج الكامل أو العينة هو **50MB للملف الأصلي**، مع حد طلب خادمي مناسب لترميز base64. بقي إثبات التحويل بحد أصغر لأنه لا يحتاج إلى حجم ملف المنتج. الملفات تحفظ في تخزين خاص ولا تُعرض عبر روابط عامة ثابتة؛ التسليم يعتمد على رابط موقّت صادر بعد اعتماد الطلب.

تم اتخاذ قرار MVP بتأجيل **العلامة المائية الشخصية**؛ فهي غير منفذة حالياً، وسيعاد تقييمها بعد تثبيت تجربة التسليم وقياس الحاجة، مع قبول أن منع نسخ PDF بالكامل غير ممكن تقنياً. تم يدوياً إنشاء رابط جديد بعد اعتماد الطلب وفتح وتنزيل ملف PDF الصحيح، كما يثبت اختبار HTTP أن الرابط المنتهي يعيد `410` ولا يصل إلى التخزين الخاص بعد تجاوز نافذة 15 دقيقة. يبقى انتظار 15 دقيقة في بيئة التشغيل اختباراً تشغيلياً اختيارياً قبل الإطلاق العام، وليس بديلاً عن اختبار الخادم الآلي.
