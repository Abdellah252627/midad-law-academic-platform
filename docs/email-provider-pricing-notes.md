# ملاحظات أسعار مزودي البريد

تم الاطلاع على صفحات الأسعار الرسمية بتاريخ 2026-08-20.

## Resend
- الصفحة الرسمية: https://resend.com/pricing
- خطة Free: 0 دولار شهرياً، حتى 3,000 رسالة شهرياً، مع حد 100 رسالة يومياً.
- الصفحة التوثيقية: https://resend.com/docs/knowledge-base/what-is-resend-pricing

## Elastic Email
- صفحة Email API الرسمية: https://elasticemail.com/email-api-pricing
- الخطة المجانية: 0 دولار شهرياً، حتى 3,000 رسالة شهرياً، مع حد 100 رسالة يومياً.
- صفحة Email Marketing الرسمية: https://elasticemail.com/email-marketing-pricing
- الخطة المجانية للتسويق: 0 دولار شهرياً، حتى 1,000 جهة اتصال و3,000 رسالة شهرياً، مع حد 100 رسالة يومياً.

## خلاصة
كلا الخيارين يقدمان خطة مجانية متقاربة لحالة إشعار الطالب عند قبول الطلب. Resend أبسط عادةً لتكامل transactional email للمطورين، بينما Elastic Email يقدم نطاقاً أوسع من أدوات التسويق والاتصالات. يجب مراجعة الحدود الحالية قبل الإنتاج لأنها قابلة للتغيير.
